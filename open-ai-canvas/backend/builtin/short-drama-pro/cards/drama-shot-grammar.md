# 镜头语法速查

## 景别定义（按画面中人体占比）

| 景别 | 人体在画面中的比例 | 英文 | 典型用途 |
|---|---|---|---|
| 大远景 | 人极小或无 | extreme wide shot | 交代环境、渲染氛围 |
| 远景 | 全身约占画面 1/4 | wide shot / long shot | 人物与空间关系 |
| 全景 | 全身刚好入画 | full shot | 动作完整性、调度 |
| 中景 | 腰部以上 | medium shot | 对话、关系 |
| 中近景 | 胸部以上 | medium close-up | 表情、态度 |
| 近景 | 肩部以上 | close-up | 情绪变化 |
| 特写 | 面部或局部细节 | extreme close-up | 决定性瞬间、细节 |

## 机位角度

| 角度 | 心理效果 |
|---|---|
| 平视 | 客观、平等、观众与被摄者同高 |
| 俯视 | 被摄者弱、被压制、被审视 |
| 仰视 | 被摄者强、有威胁、崇高 |
| 过肩 | 观众站在某人身后，带入其视角 |
| 主观 | 观众就是这个人，强代入 |
| 荷兰角（倾斜） | 失衡、不安、失控 |

## 屏幕方向与轴线

### 180 度规则

两人对话时，画一条连接两人的假想线（轴线）。**所有机位都在线的同一侧**，
这样两人在画面上的左右关系保持一致（A 始终在左、B 始终在右）。

跳轴的后果：观众会以为人物瞬间换了位置，空间感崩掉。

### 越轴的正确方式

需要越轴时（想改变权力关系、想制造失衡），用一个**中性镜头**过渡：
- 正对两人（机位在轴线上）
- 插入一个物件特写
- 插入一个空镜
- 人物走过镜头（位置关系自然改变）

### 视线匹配

- 人物看画外，下一镜要给出他在看的东西（或明确不给，制造悬念）
- 人物视线的高度要一致：看高处的人，下一镜的物件要在相应高度
- 两人对视时，视线要在同一水平线上

## 构图惯例

| 惯例 | 说明 |
|---|---|
| 三分法 | 主体放在画面三分线上，比居中更有张力 |
| 头顶留白 | 人物头顶要留一点空间，太满会压抑，太空会孤立 |
| 视线空间 | 人物看向的方向要留更多空间（look room） |
| 前景区隔 | 用门框、树枝、人影做前景，增加纵深 |
| 引导线 | 用空间的线条把观众视线引向主体 |

## 转场方式

| 转场 | 效果 | 用在哪 |
|---|---|---|
| 硬切 | 最快、最中性 | 常规切换、节奏快 |
| 叠化 | 时间流逝、柔和过渡 | 时间跳跃、情绪余韵 |
| 划像 | 并列、对比 | 两个空间/时间的对照 |
| 白闪 | 冲击、断裂 | 峰值、突然的转折 |
| 黑场 | 段落结束、沉重 | 场景间大跳跃、集末 |
| 匹配剪辑 | 两个相似形状/动作衔接 | 巧妙的时空跨越 |
| 声音先行（J-cut） | 下一场的声音先进来 | 平滑过渡、预告 |
| 声音延后（L-cut） | 上一场的声音延续 | 情绪延续、余韵 |

## 特殊镜头类型

| 类型 | 说明 |
|---|---|
| 建立镜头 | 一场戏的第一个镜头，交代空间 |
| 反应镜头 | 拍听者的脸，展示其变化 |
| 插入镜头 | 插入细节（手、物件、文字） |
| 空镜 | 没有人物，只拍环境 |
| 主观镜头 | 从人物视角看 |
| 过肩镜头 | 越过一人肩膀拍另一人 |
| 双人镜头 | 两人同框，交代关系 |
| 定场镜头 | 影片开头交代地点时间 |

## 常见剪辑惯例

- **动作剪辑**：在动作进行中切（门开到一半切到室内），比动作完成后切更流畅
- **30 度规则**：相邻两个机位的角度差要大于 30 度，否则会像跳帧
- **匹配动作**：前一镜结尾的动作，后一镜从同一位置继续
- **视线引导**：人物看向某方向，下一镜切到他看到的东西
- **声音桥**：用声音连接两个空间，让转场不突兀

## 从视频反推时的用法

看到一帧画面，按以下顺序判读：
1. **景别**：人体占画面多少？→ 对照景别表
2. **角度**：视线高度是平、俯还是仰？→ 对照角度表
3. **机位关系**：上一镜人物在左还是右？这一镜呢？→ 判断有没有跳轴
4. **构图**：主体在画面什么位置？有没有前景？→ 记录构图特征
5. **光线**：光源方向、色温、明暗对比 → 写进 `lightingAndAtmosphere`

**注意**：只有一帧时，运镜方向要靠相邻帧对比推断。单帧只能定景别、角度、构图，
不能定「推/拉/摇/移」——需要至少两帧才能判断画面在变化。
