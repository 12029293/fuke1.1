# 剧本格式：让剧本可被引用、可被拍摄

## 为什么格式是硬要求

剧本不是给读者看的故事，是给下游（分镜、生图、配音、剪辑）用的**事实源**。格式不统一，
模型就只能自由发挥，发挥出来的就是「小说腔」和「剧情梗概」。

**`structural_invariant`**（格式错误必须修）：集标题语法、场景 ID、受支持的生产标签、来源范围。
**`craft_default`**（可据理调整）：现在时、经济动作、可执行表演提示。
**`taste_option`**（只记录选择）：对白口语度、旁白、沉默、动作段落长短。

## 1. 集标题

```md
# EP001 【集名】
```

`EP001` 是稳定集 ID，改集名不改 ID。

## 2. 场景标题

```text
## <场景ID> <内|外|内外> · <地点> · <时间/天气>
```

```md
## EP001-SC003 内 · 渡口售票室 · 雨夜
```

- 场景 ID 在同一项目中唯一且稳定；改显示名不改 ID
- 内/外/内外说明主要行动空间
- 地点用创作者可识别的名字，不写资产内部编号
- 时间/天气只保留对表演、光线、行动或连续性有用的事实

**`structural_invariant`**：每个生产场景必须有可解析的场景 ID、空间性质、地点、时间/天气。

## 3. 动作段落

普通段落 = 现在发生、可见或可表演的行动：

```md
游森把湿透的末班票压在玻璃下，手指仍挡着日期。
```

- 用**可表演动词**：走、压、藏、推、攥、别过脸、把杯子往桌上一放
- 不用心理动词：想起、意识到、感到、暗下决心、心里一沉
- 一个动作段落只写能被摄像机拍到的东西

## 4. 对白

```text
角色（可选表演提示）：台词
```

```md
游森（把票往对方那边推了推）：这张我不能给你。
```

- 冒号前是角色名，冒号后是台词。**动作叙述不能写成对白**
- 表演提示可选，只在语气/动作会影响读法时写
- 角色名保持全篇一致（不要一会儿「父亲」一会儿「爸」混用指代）
- 台词要能转成演员的一个动作或表情；转不成的删掉或改成动作

### 台词的真实性等级（反推视频时最要紧）

| 情况 | 写法 |
|---|---|
| 画面有硬字幕 | 原样录入，用 `[画面文字]` 标签 |
| 能听清（有转写） | 直接写台词 |
| 只听清几个字 | 写清的部分 + `〔听不清〕`，如 `女儿：您都99了，〔听不清〕您干嘛要一个人走过来呀？` |
| 完全听不到 | `角色：〔无对白〕`，或整场标 `〔本场无对白，仅有环境声〕` |
| 按口型/情境推断 | 写推断内容 + `〔推断〕` 标记 |

**绝对禁止**：用「父亲说了一番感谢的话」「女儿表达了担心」这类概括替掉台词。
概括不是剧本，是剧情简介。

## 5. 生产标签

行首用方括号标签，交给下游：

| 标签 | 含义 |
|---|---|
| `[VO]` | 画外音（非本场人物现场发声） |
| `[OS]` | 声源在画面外但属本场空间 |
| `[SFX]` | 需要具体音效 |
| `[画面文字]` | 屏幕上的文字：字幕卡、招牌、信件、手机屏 |
| `[连续性]` | 交接易在下游丢失的状态（持物、伤势、着装、知识状态） |
| `[转场]` | 切镜方式：硬切 / 叠化 / 划像 |

```md
[VO] 父亲：没人送我，我自己走来的。
[SFX] 拐杖点地的笃笃声，节奏很慢。
[转场] 硬切。
```

`[连续性]` 只交接**前文动作已经建立、又容易在下游丢失**的状态。不能用它证明镜头外从未发生某事。

## 6. 未知与估算

拿不准的内容一律标注，不要圆滑过渡：

- `〔听不清〕` 台词听不清
- `〔推断〕` 按口型或情境推断
- `〔估算〕` 时长、时间点估算
- `〔未看到该镜画面〕` 帧预算不足、该镜没有画面证据
- `〔原文缺失〕` 来源本身没有这段

标注是专业标记，不是失败。**编造才是失败。**

## 7. 完整示例（视频反推场景）

```md
# EP001 父亲的山路与蛋糕

## EP001-SC001 内 · 老居民楼楼道 · 日

楼道斑驳，米黄色门半开。99 岁的父亲拄着木拐杖站在门外，手里提着系红丝带的白色蛋糕盒。

[VO] 父亲：没人送我，我自己走来的。

女儿快步从门内迎出，扶住父亲的手臂。

女儿：爸，您怎么来了？〔听不清〕谁送您过来的？

[OS] 女儿：您都99了，20里山路啊，您干嘛要一个人走过来呀？

女儿扶父亲站稳，看见他手里的蛋糕盒。

父亲：今天是你75的生日，我给你带个蛋糕。路上滑摔了一下，幸好我抱得紧，没事儿，蛋糕没坏。

[转场] 硬切。
```

## 8. 剧本里不该出现的内容

- **镜头语言**：景别、角度、机位、运镜、焦段 → 归分镜.md
- **心理描写**：他想起了童年、她暗暗下定决心
- **情绪形容**：气氛变得凝重、空气仿佛凝固
- **提示词**：英文 prompt、模型参数 → 归图片/视频提示词.md
- **流程说明**：这里应该生成一个视频、此处需要配音

## 9. 交稿前自查

**可机械确认**：每个场景有合法 ID + 空间 + 地点 + 时间；每个标签在支持列表内；对白都有角色名和冒号；没有心理动词。

**需要判断**：每个动作是否可被拍；每句台词能否转成演员的一个动作；标注是否覆盖了所有不确定内容；场景数量是否与 `shots` 镜头骨架相符（不是把 27 镜压成 3 场）。
