# 剧作手艺：让每场戏真的改变什么

## 根：只写看得见、听得见的

剧本只能写两样东西：**动作**（看得见）和**对白**（听得见）。内心、情绪、动机不能直接写，
必须外化。人物在桌下撕餐巾纸让你看到他紧张，胜过一句「他很紧张」。

**剧本的功力在潜台词**：把内在外化成外在，同时让读者透过外在读到内在。on-the-nose 对白
（人物直接说出心里想的）之所以坏，就是它跳过了外化——真人不这么说话。

**视觉优先**：电影 80% 视觉、20% 听觉。能用动作表达的就不写对白。一页对白说他爱她，
不如一个他默默修好她单车的动作。

## 一、场景的发动机：目标、反对、转向、退出

一场戏不是「一个地点里发生的对话」，是**一次争取**。

| 要素 | 要求 | 反例 |
|---|---|---|
| 目标 | 能作用于现场——某人当场要拿到、阻止、隐瞒、确认什么 | 「她想念父亲」（不是目标，是状态） |
| 反对 | 不是简单说「不」，是有自己的策略和理由 | 对方只是摇头 |
| 转向 | 改变下一动作——信息、权力、关系、风险至少一项变了 | 说完了，什么也没变 |
| 退出 | 留下新的压力，让下一场必须发生 | 两人聊完各自走了 |

**`reviewed_invariant`**：每场必须改变信息、权力、关系、情绪、物理状态或风险之一。无变化的场删掉或合并。

核心阻力的转向要有可追溯的事实、筹码、权限、代价或人物行动，**不能只靠对手停止反应**。

### 把一拍写成艰难选择时，两个方向都要活着

如果场景的核心是「他必须在 A 和 B 之间选」，那么 A 和 B 都得有真实的拉力：
- A 的代价是什么？放弃 A 会失去什么具体的东西？
- B 的诱惑在哪里？不是抽象的「良心」，是具体的、能拍出来的人或事。
- 两边都写活了，选择才有重量。一边明显是坏选项，就不是选择，是走流程。

## 二、把内在意义写成可表演行动

### 区分意义与载体

| 意义（不能写） | 载体（可以写） |
|---|---|
| 他很紧张 | 手指反复摩挲杯沿，第三次数杯垫 |
| 她不想让他走 | 站在门口，手还搭在门把上没松开 |
| 关系已经破裂 | 两人隔着桌子坐，中间的空椅子没人去坐 |
| 他在隐瞒 | 回答前先看了一眼门口 |

### 用可表演动词

**可表演**：走、停、转身、坐下、拿起、放下、推、拉、攥、松开、点头、摇头、别过脸、弯腰、伸手、退后一步。

**不可表演**：感到、意识到、想起、明白、决定、忍住、压抑、涌起、泛起。

后者要么改写成前者的组合，要么删掉。

### 让反应承担后果

反应镜头不是「给个表情」，是**观众看到某人因此改变了什么**。
如果反应不改变任何后续行动，这个反应就是废镜头。

### 能演的不说：VO、内心独白与痛点

`[VO]` 和内心独白是**不得已的手段**，不是常规工具。能用画面演的，不要用旁白交代。
只有在以下情况才用 VO：时间跨度无法用画面压缩、视角人物的信息差是核心机制、
原著本身是第一人称叙事且这是其质地。

## 三、用空间、物件与反应组织冲突

### 空间是可用关系

同一个空间里的位置关系就是权力关系。谁站着谁坐着、谁在门内谁在门外、
谁能走到谁身边谁不能——这些不需要台词就说明了关系。

设计场景时先问：这场戏的两个人，在空间里的位置是什么？这个位置本身在说什么？
中途位置变了吗？变了就是转向。

### 物件要进入行动链

道具不是背景。它要么被人使用、要么被人争夺、要么被人藏起、要么被人看见。
一个从头到尾没被碰过的道具，在剧本里是多余的。

**物件进入行动链**的例子：蛋糕盒 → 父亲提着它走了 20 里 → 摔倒时抱紧它 → 女儿看见它 →
父亲把它递过去 → 女儿捏着钱包眼眶红。每一环都改变关系。

### 证据先改变判断，再改变关系

如果场景的核心是一个物证（一封信、一张照片、一段录音），顺序必须是：
**看见证据 → 判断改变 → 关系改变 → 行动改变**。

跳过「判断改变」直接到「关系破裂」，观众会觉得人物反应过度。

### 主要配角有策略，事务角色不硬加戏

承担主要冲突的配角，要有相称的目标、判断或策略。事务性、环境性角色（服务员、路人、
背景同事）保持简洁，不要为了「人物立体」硬加秘密、反转或人物弧。

### 人多的场次：先解决「谁是谁」

三人以上的场次，先让观众分清谁是谁、各自站哪边，再推进冲突。
否则观众在辨认人物，没在跟故事。

## 四、节奏来自压力变化

节奏不是「快」或「慢」，是**压力的升降**。

- **加速**：缩短镜头时长、减少停顿、增加信息密度、让台词互相打断
- **留出呼吸**：一个静止的空镜、一句没说完的话、一个停顿。呼吸不是拖，是让观众消化
- **倒计时先算动作，不要只写数字**：写「还剩 3 分钟」不如写「他还有三个房间要搜」——
  观众能数得清、能跟着紧张
- **有限单位按完成状态计数**：如果题面限定「三次机会」，就要让每一次都有明确的
  「用掉了/没用掉」的状态，不能模糊带过

### 项目节奏档案

如果项目已声明节奏偏好（如结尾停在峰值 `end_on_peak`），写结尾时服从它：
- `end_on_peak: true` → 停在峰值上，不接余韵
- 否则可以用推进、留白、反讽、安静收束、形成余韵，或让既有动作变义

## 五、开场与收束

### 开场接住进入状态

全集第一拍应能独立形成钩子。观众在这一拍结束时，应该已经知道：
谁在要什么、阻力在哪、为什么现在必须发生。

不要用「背景介绍」开场。用**正在进行中的动作**开场——已经开始了，观众自己会补上下文。

### 收束完成本集承诺

结尾不是「把话说圆」，是**兑现本集答应给观众的体验**。可以是推进、留白、反讽、
安静收束、形成余韵，或让既有动作变义。不强制追加外部事件。

### 写清退出状态

已建立的代价、不可逆后果、关键持物、空间和知识状态，要进入可追溯的退出状态，
交给下一集。用 `[连续性]` 交接。

## 六、修订：十一遍

交稿前按顺序过，每遍只盯一件事：

| 遍 | 只问一个问题 |
|---|---|
| 因果遍 | 每个行动有没有原因？每个结果有没有来源？ |
| 选择遍 | 核心选择两边都活着吗？还是一边明显是坏选项？ |
| 证据遍 | 证据是否先改变判断再改变关系？ |
| 场景遍 | 每场都改变什么了吗？哪场可以删？ |
| 可表演遍 | 每个动词都能被演员做出来吗？ |
| 具体性遍 | 「一些」「有点」「某种」能换成具体的东西吗？ |
| 生产事实遍 | 持物、着装、伤势、时间是否前后一致？ |
| 声音与潜台词遍 | 有没有把潜台词说破？有没有解释观众已经看懂的？ |
| 扫读遍 | 一遍读下来，哪里卡住、哪里想跳过？ |
| 经济性遍 | 有没有重复验证、解释、同义收尾？ |
| 所有权遍 | 有没有增加来源里没有的精确数字、记录链或机关？ |

**经济性遍的重点**：删重复验证（同一个信息说了两遍）、删解释（观众已经看懂的）、
删同义收尾（已经收住了还再补一句）。峰值上有铺垫的爆发、紧跟其后的宣判句、
收住这一拍的动作，这三者不算同义收尾，不要误删。

## 七、反推视频时的额外约束

反推（看片写剧本）与正向创作不同，有一组额外纪律：

1. **不补造来源没有的东西**。原片没有的台词、动作、人物、道具，不许加。
2. **不为了「戏剧完整」改写原片结构**。原片的节奏、场次、转折点就是事实。
3. **不确定的标注，不要圆滑填平**。见 `drama-script-format` 的未知标注一节。
4. **镜头骨架优先**。剧本的场景划分要服从 `shots` 的镜头结构，不能凭叙事直觉重划。
