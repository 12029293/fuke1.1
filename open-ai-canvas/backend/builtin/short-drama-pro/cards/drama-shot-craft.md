# 镜头设计：先落实原文，再追求画面

## 铁律：每个剧本段都要有处理结果

`SHT-01`：每个与制作有关的剧本段都有明确处理——**由镜头落实**、**有理由地省略**、
或**因新的观众体验而有意重复**。

先在上下文里把剧本段与镜头对应起来，再设计镜头。这份对应只用于检查责任，
不另建产物，也不要求「一段一镜」：
- 连续表演和空间关系能守住原意时，几段原文可以合在一镜
- 揭示、反应、证据细节或空间变化很重要时，一段原文也可以由几镜承担

### 动作落实表

**`SHT-08 · reviewed_invariant`**：每个有权威来源的动作只有一个主要落实镜头；
其他镜头若再次涉及该动作，必须增加反应、细节或对原信息的新理解。

| 来源动作 | 主要落实镜头 | 动作前事实 | 动作后事实 | 其他镜头的作用 |
|---|---|---|---|---|
| 右手从衣内取令牌 | SHOT-02 | 令牌在衣内 | 右手持令牌 | SHOT-03 只展示纹样和接收者反应 |

- 只有主要落实镜头可以把状态从动作前改成动作后
- 前一镜的结束状态不得在没有来源动作时提前变成动作后状态
- 后一镜已从动作后状态开始时，运动规格不得再完整表演一次该动作
- 其他镜头要写清自己负责细节、反应还是重新解释，**不能成为第二个主要落实镜头**

### 冲击重复（唯一例外）

情绪爆发、打脸或重大反转那一下，可以把同一个关键动作从两三个角度各给一次。
这是有意的选择，所以要写出来：
- 重复镜写「冲击重复：SHOT-xxx」，指向主要落实镜头
- **状态只改变一次**：每个重复镜都从同一动作前状态走到同一动作后状态，
  第二遍不能在第一遍的结果上再做一次
- 重复镜之间起止不衔接，这是这项选择本身
- **只用在峰值**。一集里处处重复，就没有哪一下是冲击了

## 镜头目的

`SHT-02`：镜头守住来源原意，并说明**观众或人物在本镜结束时发生了什么变化**。
只有漂亮画面、没有戏剧职责的镜头，不能通过审查。

### 设计顺序（顺序不能反）

1. 找出来源中的关键动作：行动、台词、发现、拒绝、转手或揭示
2. 说明观众或人物因此发生什么变化
3. 决定本镜主要从谁的体验组织画面
4. 确定开始和结束时必须看见什么
5. **最后**才选择景别、摄影机行为和切镜点

「中景展示人物说话」不算足够的镜头目的。

镜头可以负责：建立空间、让观众站到某个人物一边、展示证据、暂缓信息、
转移权力、表现反应、让后果无法回避。

## 场面调度与地理

### 先定地理，再定机位

在任何镜头设计之前，先回答：
- 这个空间里，人和物在哪里？（画一张平面关系）
- 谁离谁近、谁离门近、谁能看见谁？
- 有没有遮挡、隔断、高度差？

**轴线与视线**：两人对话时，保持他们在画面上的左右关系一致（不要跳轴）。
需要越轴时，用一个中性镜头（正对、或插入物件特写）过渡。

### 站位是权力关系

谁站着谁坐着、谁在门内谁在门外、谁能走到谁身边谁不能——不需要台词就说明了关系。
设计时先问：这场戏的位置关系在说什么？中途变了吗？变了就是转向。

### 景别与摄影机动机

景别不是「远中近特」的填空，是**观众与被摄对象的距离感**。

| 景别 | 观众位置 | 用在哪 |
|---|---|---|
| 大全景 | 旁观者 | 交代环境、显示人的渺小或孤立 |
| 全景 | 观察者 | 交代人物与空间关系、动作完整性 |
| 中景 | 同行者 | 对话、关系、姿态 |
| 近景 | 靠近者 | 情绪变化、反应 |
| 特写 | 侵入者 | 关键细节、决定性瞬间 |

**摄影机动机**：镜头为什么要动？
- 跟随人物移动（观众跟着走）
- 揭示新信息（摇出一个藏在画外的东西）
- 传递情绪（缓慢推近=压力增加，快速甩=失控）
- **没有动机的运镜就是炫技**。固定镜头常常比运动更有力——让观众自己去看。

### 运镜逐镜选

| 运镜 | 效果 | 别用在哪 |
|---|---|---|
| 固定 | 客观、稳定、让画面自己说话 | 需要跟随快节奏动作时 |
| 推 | 压力增加、注意力收窄 | 已经很近时再推会失真 |
| 拉 | 抽离、揭示环境、孤立人物 | 情绪峰值时拉远会泄气 |
| 摇 | 揭示空间、连接两点 | 摇太快会晕 |
| 跟 | 陪伴感、行动连续 | 长跟容易单调 |
| 手持 | 现场感、不安 | 需要稳定构图时 |

## 时长与切镜

**`craft_default`**：时长服从动作完成所需的时间，不是平均分配。

- 一镜的时长 = 动作开始到动作完成 + 观众理解所需的一点余量
- 切点应落在**动作完成的瞬间**或**观众刚看懂的瞬间**，不是时间到了就切
- 短镜头（<1s）用于冲击、闪回、节奏加速
- 长镜头（>5s）用于让观众进入状态、观察细节、感受压力累积

**从视频反推时**：时长直接取 `shots[i].durationS`，这是实测值，不要估算。

## 首尾成对

每镜要写清**起点状态**和**终点状态**，并且：
- 前一镜的终点 = 后一镜的起点（除非有明确的时间跳跃或省略）
- 状态变化只能发生在「主要落实镜头」里
- 相连镜头之间的空间、光线、持物、着装要连续

## 相连边界（`CON-01`）

相邻两镜之间，以下任一项改变时必须显式说明：
- 空间位置（人物移动了）
- 时间（过了多久）
- 光线（从白天到黄昏）
- 持物（手里的东西换了）
- 着装（衣服变了）

不说明就是穿帮。

## 一镜到底还是切开

| 选择 | 适合 | 代价 |
|---|---|---|
| 一镜到底 | 连续行动、空间探索、紧张追逐、想让观众无法逃避 | 调度复杂、失误成本高、无法剪掉多余部分 |
| 切开 | 需要控制节奏、突出重点、隐藏省略 | 需要处理相连边界、可能跳轴 |

判断依据：**观众需要感受到时间的连续，还是需要被引导注意力？**
前者用长镜，后者用切镜。

## 常见问题

| 现象 | 原因 | 修法 |
|---|---|---|
| 分镜和剧本对不上 | 没做「原文落实」对应 | 逐段核对：这段原文由哪一镜落实？ |
| 镜头很漂亮但没作用 | 没有镜头目的 | 补写「观众/人物在本镜结束时改变了什么」 |
| 对话戏全是正反打 | 没设计调度 | 先定空间位置关系，找有戏剧意义的机位 |
| 跳轴 | 越轴没有过渡 | 加中性镜头过渡，或重排机位 |
| 动作重复演两遍 | 没有区分主要落实镜头 | 指定唯一的主要落实镜头，其他镜写清职责 |
| 分镜比 `shots` 少很多 | 把「场」当成了「镜」 | 一个 `shots` 条目 = 一行分镜 |

## 审查问题

交稿前逐条问：
1. 每个剧本段都有处理结果吗（落实/省略/重复）？
2. 每镜都有明确的镜头目的吗？
3. 空间地理清楚吗？观众知道人和物在哪吗？
4. 景别选择有动机吗，还是填空？
5. 运镜有动机吗？固定会不会更好？
6. 时长服从动作吗，还是平均分配？
7. 首尾状态对得上吗？
8. 相连边界都交代了吗？
9. 分镜行数是否与 `shots` 的镜头数相符？
